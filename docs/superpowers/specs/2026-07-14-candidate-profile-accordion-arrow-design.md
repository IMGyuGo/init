# 지원자 프로필 아코디언 화살표 디자인

## 목표

지원자 프로필 아코디언의 확장 상태 표시를 `+`/`-` 대신 방향 화살표로 표현한다.

## 동작

- 닫힌 상태: `▼`
- 열린 상태: `▲`
- 아이콘은 장식 요소이므로 기존 `aria-hidden="true"`를 유지한다.
- 버튼의 실제 상태는 기존 `aria-expanded`로 전달한다.

## 구현 범위

`CandidateProfileSection`의 `Accordion` 컴포넌트에서 상태 아이콘 렌더링만 변경한다. 레이아웃, 토글 동작, API 및 데이터 모델은 변경하지 않는다.

## 검증

열림 상태에 따른 아이콘 선택을 순수 함수 테스트로 먼저 고정하고, 프런트엔드 린트와 관련 테스트를 실행한다.
